# 귀멸의 칼날 랜덤 디펜스 (Demon Slayer Random Defense)

> **"마음을 불태워라. 한계는 없다."**
>
> 인기 애니메이션 **'귀멸의 칼날'** IP를 활용한 팬메이드 웹 랜덤 디펜스 게임입니다. **Phaser.js**로 구현된 타격감 있는 전투와 **Socket.IO**를 이용한 **실시간 멀티플레이**, 그리고 **Python 강화학습(RL)** 기반 자동 플레이를 지원합니다.

---

## 🎮 게임 모드 (Game Modes)

본 게임은 플레이어의 숙련도에 따라 3가지 모드 + RL 모드를 제공합니다.

### 📘 스토리 모드 (Normal)

- **목표:** 90라운드 최종 보스 **'키부츠지 무잔'** 토벌.
- **특징:**
  - 초심자를 위한 표준 난이도.
  - 보스를 처치하면 감동적인 **엔딩 크레딧**과 함께 게임이 클리어됩니다.
  - 별도의 클리어 랭킹이 기록됩니다.

### 📕 지옥 모드 (Hard)

- **목표:** **무한 라운드** 생존 (랭커 도전).
- **특징:**
  - **초반부터 강력함:** 적 체력이 1.5배 높게 시작하며, 10라운드부터 급격히 강해집니다.
  - **지옥의 난이도:** 90라운드 이후부터는 체력이 기하급수적(복리)으로 증가하여, 한순간의 방심이 패배로 이어집니다.
  - 끝이 없습니다. 당신의 한계를 시험하세요.

### 💜 협동 모드 (Multiplayer)

- **목표:** 동료와 함께 협력하여 적을 막아내세요.
- **특징:**
  - **Socket.IO** 기반 실시간 2인 협동 플레이.
  - **[동기화 시스템]:** 적 생성, 이동, 체력, 사망 여부가 실시간으로 공유됩니다.
  - **[공동 전투]:** 내가 설치한 유닛을 동료의 화면에서도 볼 수 있으며, 함께 공격합니다.

### 🤖 RL 모드 (강화학습)

- **목표:** 에이전트가 학습을 통해 지옥 모드(Hard) 무한 라운드 최대 생존.
- **특징:**
  - **다중 알고리즘:** MaskablePPO, RecurrentPPO, DQN 중 선택 가능.
  - **알고리즘별 리워드:** 각 알고리즘 특성에 맞춘 분리된 보상 파일 (rewards_ppo/dqn/recurrent).
  - **Python Gymnasium 환경:** 게임 전체 메커니즘을 순수 Python으로 시뮬레이션 (빠른 학습).
  - **173 이산 행동:** 대기 / 소환 / 배치(57종) / 판매(57종) / 조합(54종, 히든 7개 포함) / 매크로 3종.
  - **Action Masking:** 불가능한 행동 자동 차단 (골드 부족, 그리드 가득 참, 재료 없음 등).
  - **히든 조합 탐색:** 에이전트가 히든 레시피 발견 시 **1.5배 보상** 보너스.
  - **시너지 시스템:** T6 유닛 3명 조합 시 공격력 **1.2배** 보너스 (10개 시너지).
  - **WebSocket 브릿지:** 학습된 모델이 실제 브라우저 게임을 실시간 조종.
  - **AI 대전 모드:** 학습된 에이전트끼리 내부 환경에서 병렬 시뮬레이션 대결.

## ✨ 주요 기능

- **전략적 랜덤 소환:** 골드를 모아 일반~희귀 등급 대원을 소환합니다.
- **확정 조합 시스템 (Recipe):** 확률 싸움은 그만! **100% 성공**하는 조합법으로 상위 유닛을 제작하세요.
- **쾌적한 조작감:**
  - **스페이스바(Space):** 유닛 즉시 판매 단축키 지원.
  - **배속 모드:** 1배속 / 2배속 토글 기능으로 속도감 있는 플레이.
  - **가이드 팝업:** 인게임에서 언제든 조합법 확인 가능.
- **화려한 연출:**
  - 전용 타격 이펙트 및 투사체 애니메이션.
  - 십이귀월 보스 등장 시 전용 **컷신(Cutscene)** 및 경고 연출.
  - 메뉴 화면의 부드러운 배경 전환 효과.
- **히든 조합 시스템:** 일반 조합법에 표시되지 않는 **7개의 비밀 레시피**가 존재합니다.
  - 특수 재료 조합으로 숨겨진 T5/T6 유닛을 발견하세요.
  - RL 에이전트가 히든 조합을 발견하면 **+1.5배 보상**을 받습니다.
- **시너지 시스템 (T6):** 특정 T6 유닛 3명을 함께 필드에 배치하면 공격력 **1.2배** 버프가 활성됩니다.

### 사거리(Range) 기반 전투 모델

실제 게임에서 적은 반경 280px 궤도를 순회합니다. 사거리가 짧은 유닛은 보스 라운드(단일 대상)에서 실효 DPS가 떨어집니다.

| 등급 | 사거리 범위 | 보스전 DPS 효율 | 비고                      |
| :--: | :---------: | :-------------: | :------------------------ |
|  T1  |   80-100    |     70-75%      | 배치보다 조합 재료로 활용 |
|  T2  |   90-220    |     73-100%     | 겐야(220)는 풀 효율       |
|  T3  |   100-140   |     75-85%      | 중간 효율                 |
|  T4  |   140-170   |     85-93%      | 주력 전력                 |
|  T5  |   150-210   |     88-100%     | 고효율                    |
|  T6  |   150-230   |     88-100%     | 최강 전력                 |

- **일반 라운드** (다수 적): 모든 유닛 100% DPS (항상 사거리 내 적 존재)
- **보스 라운드** (단일 대상): 사거리 효율 적용 → 고티어 유닛 필수
- **실제 게임 배치**: RL이 사거리에 따라 최적 위치에 자동 배치 (짧은 사거리 → 궤도 근처, 긴 사거리 → 중앙)

### 보상 체계

> 알고리즘별 리워드 파일이 분리되어 있습니다 (rewards_ppo / rewards_dqn / rewards_recurrent).

| 이벤트       | 보상 (PPO 기준)                    | 설명                             |
| :----------- | :--------------------------------- | :------------------------------- |
| 라운드 생존  | +1.5 + round/20, 10R 단위 추가 보너스 | 생존 목표를 더 강하게 유도        |
| 유닛 배치    | 0.1 × tier                         | 배치는 보조 보상                  |
| 조합 성공    | 0.18 × tier² + 고티어 추가 보너스  | T5/T6 조합을 더 강하게 유도       |
| 히든 조합    | 조합 보상 × **1.5**                | 히든 레시피 발견 시 추가 보너스    |
| 보스 처치    | +18.0                              | 보스 클리어 가치 상향             |
| 판매         | 0.0                                | 판매 자체는 보상하지 않음         |
| 적 초과/실패 | -10.0                              | 게임 오버 패널티 강화             |

### 사용법

**1단계: 의존성 설치**

```bash
# Node.js 서버 의존성
cd MyDefenseGame
npm install

# Python RL 의존성
cd python
pip install -r requirements.txt
```

**2단계: 학습 시작**

```bash
cd python

# MaskablePPO (기본) 학습
python train.py

# RecurrentPPO (LSTM) 학습
python train.py --algorithm recurrent

# DQN 학습
python train.py --algorithm dqn

# 최신 체크포인트에서 자동 이어하기
python train.py --resume

# 특정 체크포인트 지정도 가능
python train.py --resume ./models/ppo/demon_slayer_1000000_steps.zip
```

- 학습 과정 모니터링

```bash
# python 폴더 안에서 실행할 때
tensorboard --logdir tb_logs

# 프로젝트 루트에서 실행할 때
tensorboard --logdir python/tb_logs
```

- Python 3.12 가상환경에서 `ModuleNotFoundError: No module named 'pkg_resources'`가 뜨면 먼저 아래를 실행합니다.

```bash
python -m pip install setuptools
```

**3단계: 학습 결과 평가**

```bash
cd python

# PPO 베스트 모델 평가
python train.py --eval models/ppo/best_model.zip --algorithm ppo

# RecurrentPPO 베스트 모델 평가
python train.py --eval models/recurrent/best_model.zip --algorithm recurrent

# DQN 베스트 모델 평가
python train.py --eval models/dqn/best_model.zip --algorithm dqn
```

**4단계: 실제 게임에서 시각적 테스트**

```bash
# 터미널 1: 게임 서버 실행
cd MyDefenseGame
node server.js

# 터미널 2: RL 브릿지 실행
cd python
python rl_bridge.py --model models/ppo/best_model.zip --algorithm ppo

# 브라우저에서 접속: http://localhost:3000/?rl=true
# → 좌상단 RL 오버레이에서 AI 행동/DPS/라운드 실시간 확인
```

프로젝트 루트에서 바로 실행하려면 아래처럼 경로를 모두 포함해야 합니다.

```bash
python python/rl_bridge.py --model python/models/ppo/best_model.zip --algorithm ppo
```

베스트 모델 관전 흐름은 아래 순서가 맞습니다.

```bash
# 1. 학습은 python 폴더에서 실행
cd python
python train.py --algorithm ppo --resume

# 2. 다른 터미널에서 서버 실행
cd ..
node server.js

# 3. 다른 터미널에서 현재 베스트 모델 관전
cd python
python rl_bridge.py --model models/ppo/best_model.zip --algorithm ppo
```

- RL 오버레이의 `모델 선택` 버튼으로 `python/models/{ppo,recurrent,dqn}` 아래의 다른 모델도 즉시 교체해서 볼 수 있습니다.
